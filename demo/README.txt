MCP DAW - the demo
==================

Double-click "Run Demo" (Windows) or run ./run-demo.sh (Linux). MCP DAW opens by itself and,
over about four minutes, builds and performs three songs while they play. Keep your hands off
the app until the console window says "Done"; close the console window to stop early.

The demo starts a new project. If you have unsaved work open in MCP DAW, save it first - the
demo stops rather than throw it away.

What is in this folder
  Run Demo.cmd / run-demo.sh   start the demo
  demo-script.txt              the demo itself: timed MCP commands (see docs/SCRIPTING.md)
  kens-demo-2.mcpdaw           the three songs as MCP DAW projects, in playing order:
  kens-demo-3.mcpdaw             2 = drum & bass, 3 = halftime dub, 1 = hip-hop beat.
  kens-demo-1.mcpdaw             Open them in MCP DAW (File > Open) to explore or remix.
  samples\                     the WAV files they use (credits: samples\CREDITS.txt)

For developers: demo-script.txt is generated by tools/make_demo.py from the three projects,
so the songs can be changed in MCP DAW and the demo re-generated ("make_demo.py build").
