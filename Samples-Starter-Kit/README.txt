MCP DAW - Samples Starter Kit
=============================

A small kit of drums, percussion, bass notes and texture to get going with. MCP DAW's browser
opens this folder the first time you start the app: click a file to hear it, drag it onto the
arrangement to use it.

  Kicks        kick-deep-clean, kick-mid-clean, kick-slight-distrotion
  Snares       snare-basic, snare-phaser
  Claps        clap, kens-clap
  Toms         tom-high, tom-mid, tom-low
  Cymbals      cymbal-little1, cymbal-little2
  Reverse FX   reverse-ding, reverse-percusion-cymbal, reverse-tapping-stick
  Bass notes   55hz-sine-wave_bass-note-A1        a pure 55 Hz sine (note A1): pitch it with
               55Hz-decending_bass-note-A1        right-click > Pitch for a bassline, add
               55Hz-decending-fast_bass-note-A1   distortion for grit
  Texture      end-of-song-vinyl-silent-crackle_loop   vinyl crackle, loops

Short hits are placed as one-shots; the vinyl loop repeats when you drag its right edge.
